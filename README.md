# C Programming

Weekly C programming exercises from my university coursework (Weeks 1–18), 
covering fundamentals through file handling, structs, and algorithm design.

For a complete standalone project from this coursework — merge sort and binary 
search implemented over a merged product inventory dataset — see 
[product-sort-search](https://github.com/jamesob1100/product-sort-search).

## Structure
Each `WEEK NN` folder contains that week's exercises (`Q1.c`, `Q2.c`, etc.) 
as individual C files.

## Tech stack
C

## Build & run
Each file is self-contained — compile and run individually, e.g.:
gcc "WEEK 05/Q3.c" -o q3
./q3
